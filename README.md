## About

- 🏠 **Self-hosted** — Ubuntu Server + Docker / Portainer で自宅サーバーを運用中
- 📻 **AI Radio** — LLMで原稿を作り、VOICEVOXで読み上げる自動生成ラジオを AzuraCast で配信中
- 🎵 **Music** — SUNOバンド **After#Light**（Asahi / feat. Akari）。1stアルバム『スタートボタン』公開中
- 💡 **LED Signage** — Colorlight 5A-75B + HUB75パネル（128×64）を FPP 経由でサーバーから制御
- 📱 **nekoOS** — Pixel 2 / Surface Duo 2 向けカスタムOSプロジェクト

> 完成品の展示というより、「作って、動かして、直していく過程」ごと置いてある場所です。
